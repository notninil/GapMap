## Verification limits

- A live MySQL server and Docker engine were not available for execution here. MySQL/Docker startup is configured, but it was not run in this environment.
- The browser-preview service could render React but could not load Java's `libjli.so`. Therefore authenticated frontend workflows and mobile viewport behavior have not been browser-tested end to end. Backend HTTP workflows and the production frontend build were verified independently.
- The application has not been deployed to a public hosting service. Sites hosting cannot execute a Java/MySQL backend.
- There is no automated frontend browser test suite in this delivery.

These limits are distinct from test failures: all executed automated backend tests and the frontend production build passed.
