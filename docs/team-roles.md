# GapMap Team Roles & Responsibility Matrix

## Team Structure & Collaborative Development Model
All three team members share primary full-stack responsibilities—working across frontend UI components, backend Spring Boot APIs, and MySQL database setup—while taking turns on implementation tasks. In addition to shared core development, individual team members lead specific administrative and design focus areas:

* **Imee Cabahug (Project Lead & Full-Stack Developer):** Lead for Trello workspace setup, task board management, sprint tracking, full-stack feature development, and database configuration.
* **Ryza Janell Mutya (UI Lead & Full-Stack Developer):** Lead for user interface layout design, visual styling, feature content creation, full-stack feature development, and frontend integration.
* **Carlo Jose Labagala (Full-Stack Developer & QA):** Collaborative full-stack feature development, API integration, database schema verification, and testing.

---

## Shared Development Responsibilities
Because all members contribute across the entire application lifecycle, the following tasks are performed collaboratively and rotated among all three members:

- **Frontend Development:** Building React components, connecting Axios HTTP calls, managing application state, and refining user flows.
- **Backend Development:** Writing Spring Boot REST controllers, defining JPA entity relationships, and updating service logic.
- **Database & Schema Updates:** Testing MySQL queries, verifying table structures in phpMyAdmin, and maintaining data seed logic.
- **Testing & Peer Review:** Reviewing pull requests, verifying branch merges, and testing features against acceptance criteria.
